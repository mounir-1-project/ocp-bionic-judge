# Analytics — Indicateurs opérationnels

Ce dossier calcule les KPI du système de surveillance.

## Fichiers

| Fichier | Rôle |
|---------|------|
| `kpi.py` | Indicateurs : disponibilité, taux de signalement, corrélation, etc. |

## Indicateurs calculés

- **Disponibilité des mesures** — % de données valides
- **Taux de signalement** — % d'heures avec alertes
- **Exposition corrosive** — Heures en conditions agressives
- **Marche sous consigne** — % de temps en sur-refroidissement
- **Stabilité régulation** — Comportement de la boucle de régulation
