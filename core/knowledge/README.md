# Connaissance métier

Ce dossier contient les données de référence du refroidisseur E7301.

## Fichiers

| Fichier | Rôle |
|---------|------|
| `knowledge.py` | Chargement et accès à la connaissance métier |
| `amdec.yaml` | Analyse AMDEC (modes de défaillance, criticités) |
| `tags.yaml` | Registry des capteurs DCS (seuils, plages) |
| `topology.yaml` | Topologie physique (pièces, capteurs, positions) |

## Données

- **AMDEC** : 13 modes de défaillance avec cotations F/G/N/C
- **Tags** : 12 capteurs DCS avec seuils d'alarme
- **Topologie** : Position physique des capteurs pour le modèle 3D
